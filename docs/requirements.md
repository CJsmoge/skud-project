# Требования

## Функциональные требования

| ID | Требование | Источник | Приоритет |
|---|---|---|---|
| FR-01 | Система должна регистрировать сотрудников (ФИО, должность, отдел) | Администратор | Must |
| FR-02 | Система должна выдавать электронные карты сотрудникам | Администратор | Must |
| FR-03 | Система должна блокировать карту по запросу администратора | Администратор | Must |
| FR-04 | Система должна фиксировать событие прохода (кто, когда, куда) | Турникет | Must |
| FR-05 | Система должна отображать журнал событий в реальном времени | Охрана | Must |
| FR-06 | Система должна разрешать поиск событий по дате и сотруднику | Охрана | Should |
| FR-07 | Система должна фильтровать события по зоне доступа | Охрана | Should |
| FR-08 | Система должна формировать отчёт по посещаемости за период | Администратор | Should |
| FR-09 | Система должна экспортировать отчёты в CSV | Администратор | Could |
| FR-10 | Система должна управлять зонами доступа | Администратор | Must |
| FR-11 | Система должна назначать сотруднику уровень доступа | Администратор | Must |
| FR-12 | Система должна разграничивать права по ролям (сотрудник, охрана, администратор) | Администратор | Must |
| FR-13 | Система должна искать карту по ФИО сотрудника | Администратор | Should |
| FR-14 | Система должна выдавать несколько карт за раз (массово) | Администратор | Should |
| FR-15 | Система должна формировать отчёт по выданным/заблокированным картам | Администратор | Should |

## Проверка качества

- **Полнота:** все сценарии покрыты ✅
- **Непротиворечивость:** конфликтов нет ✅
- **Выполнимость:** реализуемо за 4 недели ✅

### Матрица «ценность × сложность»

|  | Низкая сложность | Высокая сложность |
|---|---|---|
| **Высокая ценность** | FR-01, FR-02, FR-04, FR-05 | FR-03, FR-10, FR-11, FR-12 |
| **Низкая ценность** | FR-09, FR-15 | FR-16 (отказаться) |

**Решения:**
- **Делать сразу:** FR-01, FR-02, FR-04, FR-05.
- **Планировать:** FR-03, FR-10, FR-11, FR-12.
- **Опционально:** FR-09, FR-15.
- **Отказаться в MVP:** FR-16.
