# Сущности и атрибуты

## Сущность: Employee (Сотрудник)

**Назначение:** описывает сотрудника организации.

**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT (SERIAL) | Да | PK |
| full_name | VARCHAR(100) | Да | ФИО |
| department | VARCHAR(100) | Да | Отдел |
| position | VARCHAR(100) | Да | Должность |
| phone | VARCHAR(20) | Нет | Телефон |
| email | VARCHAR(255) | Нет | Email |
| created_at | TIMESTAMP | Да | Дата создания |

## Сущность: Card (Карта)

**Назначение:** электронная карта доступа.

**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT (SERIAL) | Да | PK |
| employee_id | INT (FK) | Да | Владелец карты |
| number | VARCHAR(20) | Да | Номер карты (уникальный) |
| status | VARCHAR(20) | Да | Статус (active/blocked) |
| issued_at | TIMESTAMP | Да | Дата выдачи |
| blocked_at | TIMESTAMP | Нет | Дата блокировки |

## Сущность: Zone (Зона доступа)

**Назначение:** территория, куда разрешён вход.

**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT (SERIAL) | Да | PK |
| name | VARCHAR(100) | Да | Название зоны |
| description | TEXT | Нет | Описание |
| level_id | INT (FK) | Нет | Уровень доступа |

## Сущность: AccessLevel (Уровень доступа)

**Назначение:** набор зон, разрешённых сотруднику.

**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT (SERIAL) | Да | PK |
| name | VARCHAR(50) | Да | Название уровня |
| description | TEXT | Нет | Описание |

## Сущность: Request (Событие прохода)

**Назначение:** фиксирует факт прохода через турникет.

**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT (SERIAL) | Да | PK |
| employee_id | INT (FK) | Да | Сотрудник |
| card_id | INT (FK) | Да | Карта |
| zone_id | INT (FK) | Да | Зона |
| controller_id | INT (FK) | Да | Турникет |
| event_time | TIMESTAMP | Да | Время события |
| direction | VARCHAR(10) | Да | Направление (in/out) |

## Сущность: Controller (Контроллер)

**Назначение:** устройство, считывающее карту (турникет).

**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT (SERIAL) | Да | PK |
| zone_id | INT (FK) | Да | Зона |
| name | VARCHAR(100) | Да | Название |
| location | VARCHAR(255) | Нет | Расположение |
| is_active | BOOLEAN | Да | Активен |

## Сущность: StatusHistory (История статуса карты)

**Назначение:** хранит все изменения статуса карты.

**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT (SERIAL) | Да | PK |
| card_id | INT (FK) | Да | Карта |
| old_status | VARCHAR(20) | Да | Старый статус |
| new_status | VARCHAR(20) | Да | Новый статус |
| changed_at | TIMESTAMP | Да | Дата изменения |

## Итого

- **7 сущностей.**
- **У каждой — PK (id).**
- **FK:** employee_id, card_id, zone_id, controller_id, level_id.
- **Типы:** INT, VARCHAR, TEXT, TIMESTAMP, BOOLEAN.
