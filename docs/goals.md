# Цели и задачи

## Главная цель (SMART)

Разработать веб-приложение для контроля и управления доступом (СКУД) на территорию организации, позволяющее сотрудникам проходить через турникеты по электронной карте, администраторам — выдавать и блокировать карты за ≤ 3 клика, а охране — видеть все события проходов в реальном времени, к 07 ноября 2026 года.

## Проверка по SMART

- **S (Specific):** веб-приложение СКУД для организации.
- **M (Measurable):** метрики — ≤ 3 клика, реальное время, онлайн-отчёты.
- **A (Achievable):** реально за 4 недели практики (1 разработчик).
- **R (Relevant):** решает боли — бумажные пропуска, очереди, ручные отчёты.
- **T (Time-bound):** срок — 07.11.2026.

## Задачи (декомпозиция)

1. Проанализировать процессы проходной и аналоги (Sigur, PERCo).
2. Спроектировать базу данных (сотрудники, карты, зоны, события).
3. Спроектировать интерфейсы для 3 ролей (сотрудник, охрана, администратор).
4. Реализовать модуль выдачи и блокировки карт.
5. Реализовать модуль журнала событий и отчётов.
6. Протестировать ключевые сценарии и подготовить документацию.

## Концепция ИР

**Назначение:** веб-приложение для автоматизации контроля и управления доступом на территорию организации.

**ЦА:** сотрудники организации, охрана, администраторы СКУД.

**Функции:**
- Выдача и блокировка электронных карт.
- Управление зонами доступа и правилами.
- Журнал событий (кто, когда, куда прошёл).
- Формирование отчётов по посещаемости.
- Разграничение прав по ролям.

**Эффект:**
- Сокращение времени оформления пропуска с 30 мин до 2 мин.
- Автоматический учёт проходов (без бумажных журналов).
- Мгновенная блокировка утерянных карт.
- Отчёты формируются онлайн, а не вручную.

**Отличия от аналогов:**
- Простой веб-интерфейс без установки тяжёлого клиента.
- Бесплатная основа для малых организаций.
- Ориентация на малый и средний бизнес.
