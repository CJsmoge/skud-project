# Целевая аудитория

## Сегмент 1: Сотрудник

| Параметр | Значение |
|---|---|
| **Who** | Сотрудник организации, 20–60 лет |
| **What** | Проходит через турникет по карте |
| **When** | Утро (приход), вечер (уход), обед |
| **Where** | Турникет на входе в здание |
| **Why** | Попасть на рабочее место |

**Боли:** очереди, карта не сработала, забыл карту.

**Потребности:** быстрый проход, восстановление карты за минуту.

## Сегмент 2: Охрана

| Параметр | Значение |
|---|---|
| **Who** | Сотрудник охраны, 25–55 лет |
| **What** | Следит за проходами, реагирует на нарушения |
| **When** | Круглосуточно (смены) |
| **Where** | Пост охраны у входа |
| **Why** | Не допустить посторонних |

**Боли:** бумажные журналы, нет онлайн-данных, сложно искать событие.

**Потребности:** журнал событий онлайн, быстрый поиск, уведомления.

## Сегмент 3: Администратор СКУД

| Параметр | Значение |
|---|---|
| **Who** | Администратор, 25–45 лет |
| **What** | Выдаёт карты, настраивает зоны и права |
| **When** | Рабочий день (09:00–18:00) |
| **Where** | Офис, компьютер |
| **Why** | Управлять доступом |

**Боли:** ручное заполнение журналов, долгая выдача карт, нет отчётов.

**Потребности:** быстрая выдача/блокировка карт, автоматические отчёты.

## Контексты использования

1. **Срочный:** сотрудник опаздывает, карта не сработала — нужен быстрый способ попасть внутрь (временный пропуск).
2. **Плановый:** администратор утром выдаёт 10 новых карт новым сотрудникам.
3. **Мобильный:** охранник обходит территорию с планшетом и видит события в реальном времени.
