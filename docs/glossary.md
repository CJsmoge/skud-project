\# Глоссарий предметной области «Электронная проходная (СКУД)»



| Термин | Определение |

|---|---|

| СКУД | Система контроля и управления доступом |

| Идентификатор | Уникальный номер карты/ключа |

| Карта | Физический носитель идентификатора |

| Сотрудник | Пользователь системы, имеющий доступ |

| Турникет | Устройство преграждения прохода |

| Контроллер | Устройство, считывающее карту |

| Зона доступа | Территория, куда разрешён вход |

| Правило доступа | Условие, при котором проход разрешён |

| Событие | Зафиксированный факт прохода |

| Журнал | Список всех событий |

| Блокировка | Запрет доступа для карты |

| Уровень доступа | Набор зон, разрешённых пользователю |
