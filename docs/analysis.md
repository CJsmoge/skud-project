# Анализ предметной области

## 1. Описание ПрО

Электронная проходная (СКУД) — система контроля и управления доступом на территорию организации. Автоматизирует учёт проходов, выдачу прав доступа и формирование отчётов по посещаемости.

## 2. Границы ПрО

| Входит | Не входит |
|---|---|
| Учёт сотрудников/студентов | Бухгалтерия, зарплата |
| Выдача и блокировка карт | Производство карт |
| Управление турникетами | Ремонт турникетов |
| Зоны доступа и правила | Видеонаблюдение |
| Журнал проходов (события) | Кадровый учёт |
| Отчёты по посещаемости | Пропуск автотранспорта |

## 4. Бизнес-процессы «AS IS»

### Процесс 1: Выдача пропуска
- **Участники:** сотрудник, охрана, администратор
- **Шаги:** заявка → проверка → выдача бумажного пропуска
- **Проблемы:** долго, легко подделать, нет единой базы

### Процесс 2: Проход через проходную
- **Участники:** сотрудник, охрана
- **Шаги:** предъявление пропуска → визуальная проверка → запись в журнал
- **Проблемы:** человеческий фактор, очереди, нет точного времени

### Процесс 3: Контроль посещаемости
- **Участники:** администратор
- **Шаги:** сбор бумажных журналов → ручной подсчёт
- **Проблемы:** долго, ошибки, нет онлайн-данных

### Процесс 4: Блокировка доступа
- **Участники:** охрана, администратор
- **Шаги:** устное распоряжение → изъятие пропуска
- **Проблемы:** не мгновенно, пропуск могут не сдать
