# 📘 Проект 1: Электронная проходная (СКУД)

Учебный проект по УП.01 ПМ.01 «Проектирование и разработка информационных ресурсов».

**Тема:** Проектирование и разработка информационного ресурса «Электронная проходная (СКУД)».

**Автор:** Филонов Кирилл Александрович, группа 2ВР-2-25.

**Период:** 12.10.2026 — 07.11.2026.

## Описание

Веб-приложение для контроля и управления доступом на территорию организации. Позволяет:
- Регистрировать сотрудников и выдавать карты.
- Блокировать утерянные карты за ≤ 3 клика.
- Фиксировать события проходов через турникеты.
- Просматривать журнал событий в реальном времени.
- Формировать отчёты по посещаемости.

# 🌐 Проект 2: Языковой портал (LinguaPro)

Учебный проект «Разработка веб-приложения на стороне клиента».

**Тема:** Создание веб-приложения «Языковой портал».

**Период:** 09.11.2026 — 14.11.2026.

## Описание

Клиент-серверное веб-приложение для языковой школы. Позволяет просматривать курсы, рассчитывать стоимость и записываться на бесплатный урок.

## Что реализовано

- **Главная страница:** девиз школы, кнопка «Записаться на бесплатный урок», 3 карточки преимуществ, слайдер с отзывами, контакты в подвале.
- **Страница «Курсы»:** карточки курсов (название, описание, цена), калькулятор стоимости (длительность × количество × тариф).
- **Страница записи:** форма с клиентской валидацией (ФИО на кириллице, маска телефона `+7(XXX)-XXX-XX-XX`, проверка email, чекбокс согласия на обработку ПДн).
- **Backend:** сервер на Node.js + Express, сохранение заявок в БД.
- **База данных:** PostgreSQL (таблицы `courses` и `applications`).
