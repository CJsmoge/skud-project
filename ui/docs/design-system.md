# Дизайн-система (СКУД)

## Цвета
| Роль | HEX | Применение |
|---|---|---|
| Primary | #2563EB | Кнопки, ссылки |
| Secondary | #64748B | Второстепенные элементы |
| Accent | #F59E0B | Акценты, статусы |
| Success | #10B981 | Успешные действия (проход разрешён) |
| Danger | #EF4444 | Ошибки, отмена (проход запрещён) |
| Text | #1E293B | Основной текст |
| Bg | #F8FAFC | Фон |

## Типографика
- **Шрифт:** Inter, system-ui, sans-serif.
- **Размеры:** H1 — 32px, H2 — 24px, Body — 16px, Small — 14px.
- **Межстрочный интервал:** 1.5.
- **Начертания:** 400 (обычный), 600 (полужирный), 700 (жирный).

## Сетка
- **Колонок:** 12.
- **Отступ между колонками:** 24px.
- **Ширина контейнера:** 1200px.

## Компоненты
- **Кнопка:** primary (синяя), secondary (серая), danger (красная), success (зелёная).
- **Карточка:** белая, с тенью, скруглённые углы (8px).
- **Поле ввода:** с рамкой, фокус — синяя рамка.
- **Таблица:** для журнала событий.
- **Бейдж:** для статусов (active/blocked).

## Сравнение Bootstrap и Tailwind (СКУД)

| Элемент | Bootstrap | Tailwind |
|---|---|---|
| Карточка | `card` + `card-body` | `bg-white rounded-xl shadow-sm p-5` |
| Кнопка | `btn btn-primary` | `bg-blue-600 hover:bg-blue-700 text-white` |
| Сетка | `row` + `col-md-6` | `grid grid-cols-1 md:grid-cols-2` |
| Sidebar скрыт на мобильном | `d-none d-lg-block` | `hidden lg:flex` |
| Таблица | `table table-hover` | `w-full text-left divide-y` |
